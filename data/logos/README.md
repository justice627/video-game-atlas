# Logo images

PNG renderings of game and series logos from Wikimedia Commons, written by `npm run fetch:logos` (rules section 8, `docs/data-rules.md`).

These files are **not** covered by the CC BY-SA licence of the tables. Each keeps its own Commons licence, recorded with its author in `data/logos.csv` and on its Commons file page (`https://commons.wikimedia.org/wiki/File:<file>`). The logos are trademarks of their owners; the atlas uses them only to identify the games they name and is not affiliated with or endorsed by any publisher.
